Privacy Policy

This policy describes how UNVEILRY Analytics Automation (the “Application”) handles data obtained from Google and YouTube services.

Purpose and operator

The Application is an internal reporting utility operated for UNVEILRY MEDIA. It is designed to analyze the authorized owner's YouTube channel performance and is not offered as a public service.

Information accessed

After explicit Google OAuth authorization, the Application may access channel-level and video-level YouTube Analytics metrics, such as views, watch time, average view duration, average percentage viewed, likes, comments, and subscriber gains. The Application requests the youtube.readonly and yt-analytics.readonly scopes. It does not request access to publish videos or change channel settings.

How information is used

These metrics are used to generate internal daily reports and assist the channel owner with content planning and performance analysis. Data is not used for advertising targeting or sold to third parties.

Storage and access

Report files are stored in a private GitHub repository and may also be retained as private GitHub Actions workflow artifacts for operational reporting. OAuth credentials are held as GitHub Actions secrets rather than published on this website. Access is limited through the permissions of the private workflow and authorized services used for reporting. No internet-connected system can be guaranteed perfectly secure.

Service providers and sharing

The Application uses Google/YouTube APIs to retrieve analytics and GitHub Actions for scheduled processing and storage. Reports may be accessed by an authorized AI-assisted reporting workflow used by the channel owner. Information is not intentionally published to the public website. Data is not sold.

Retention and deletion

Daily “latest” reports may be replaced by newer report files. GitHub workflow artifacts have configured retention periods; historical commits or backups may retain earlier versions until removed according to the relevant platform's controls. The channel owner can request removal of stored reports and revoke the Application's Google access.

Revoking access

The channel owner can revoke OAuth authorization at Google Account → Third-party connections. Revoking access stops future API requests using the revoked authorization but does not automatically erase previously generated reports; those must be removed from their storage locations separately.

Google API Services disclosures

The Application's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements, where applicable. Use of YouTube API Services is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact

For privacy inquiries, contact the application operator using the user support email displayed on the Google OAuth consent screen.
