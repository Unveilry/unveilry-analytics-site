UNVEILRY Analytics Automation

A private reporting utility built for the UNVEILRY MEDIA YouTube channel. It helps the channel owner review audience and content performance using the YouTube Analytics API.

What the application does

With the channel owner's authorization, the application reads YouTube channel and video analytics, generates reporting snapshots, and makes those reports available to the channel's private internal workflow.

The application is not a public analytics service. It is intended for use by the authorized channel owner, not for third-party users or general sign-up.

Permissions and access

The application uses Google OAuth authorization to request read-only YouTube and YouTube Analytics access. It does not request permission to upload, edit or delete videos, or modify the channel.
